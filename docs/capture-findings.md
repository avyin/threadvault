## Interpretation

The current local evidence shows that a GPT Action can send:

- user and assistant message text;
- role labels;
- message order through array order, and sometimes explicit indexes;
- summary;
- notes about completeness;
- sometimes a raw transcript;
- a model-reported `capture_report`;
- visible markdown/code formatting as text;
- user-provided fake timestamps as text;
- file/image references or descriptions when visible to the GPT.

The current local evidence does not show that GPT Actions can send:

- hidden system/developer messages;
- real timestamp metadata;
- tool/action traces as separate messages;
- raw file or image payload bytes;
- behavior near the 100,000-character payload limit;
- an authoritative exact transcript.

The observed rows support the earlier research conclusion: ThreadVault can capture a useful model-supplied transcript, but exactness and completeness still require manual comparison against the visible ChatGPT conversation.
